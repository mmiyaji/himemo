iCloud 同期 v2 の実機移行・二端末同期を確認するプレビュー版です。初版の同期先は iCloud のみです。Google Drive と Web の v2 同期は対象外です。

【移行前に必ず実施】
1. 参加する全端末で旧版の同期とクラウド整理を停止してください。旧版と v2 を混在させないでください。
2. 各端末で旧メモを ZIP に書き出し、元データも残してください。
3. 一台目で「iCloud 同期 v2」を新規登録し、SYNC と ADMIN の復旧コードを別々に安全な場所へ保管してください。Face ID／Touch IDで登録すれば管理パスワードは不要です。パスワード方式は6文字以上です。
4. ZIPの内容を確認し「管理者として一括復元・上書き」を実行してください。私用の復元先は自動で用意し、個別パスワードや添付の個別チェックは不要です。同じ元IDのメモはZIPの内容で上書きし、ZIPにないメモは保持します。
5. 二台目は同じ iCloud アカウントで、一台目のメニュー「他の端末をQRで追加」を表示し、二台目の「QRを読み取って参加」で参加してください。手入力のSYNCコードも使えます。管理機能の確認時だけ、別の管理者登録用QRまたはADMINコードも登録します。
6. 両端末でメモと添付を確認するまで、旧 ZIP と旧データを削除しないでください。初期化やクラウド削除は不要です。

【今回の確認】
・同期用QRの表示・読み取りで二台目へ参加できること。管理者用QRと混同されず、通常参加だけでは私用メモの管理権限が付かないこと。QRは秘密の復旧コードと同じ扱いです。
・カメラ権限の許可・拒否・再試行、無関係なQR、取消し、アプリ切替で安全に中断できること。iPhone縦・iPad横でもQR表示と操作が見切れないこと。
・設定で管理者モードに入った後、v2画面の「管理者として一括復元・上書き」でZIPを取り込めること。旧ビルドからの更新直後は、最初の一度だけv2生体認証・管理パスワード・ADMINコードで端末との連携が必要です。
・ZIP選択から戻ったときに処理が中断せず、確認画面へ進めること。実際に別アプリへ切り替えた場合はロックし、再操作が必要であること。
・私用プロファイル未作成でも管理者認証だけでZIPを一括復元できること。同じZIPや変更ZIPの再取り込みで重複せず、編集・削除・競合をZIPの内容で上書きできること。
・Face ID／Touch IDで登録・管理者解除・ADMINコードからの二台目設定ができること。キャンセル・ロックアウト・アプリ切替では解除状態が残らないこと。
・登録失敗時に診断コードが表示され、保留中の登録を同じ内容で再開できること。
・一台目で新規登録し、アプリを閉じて再起動しても登録とメモが復元できること。
・二台目が SYNC コードで参加し、通常メモの作成・編集・削除が両方向に同期すること。
・別のプロファイル鍵で保護した私用プロファイルが、正しいパスワードまたは管理者解除後だけ読めること。ロック中に本文や名前が表示されないこと。
・写真、動画、音声、ファイルを送受信し、受信後に開けること。途中で通信を切った後の再試行も確認してください。
・旧 ZIP の通常・私用メモと添付を選んだ復元先へ取り込めること。同じ ZIP を再度取り込んでも重複しないこと。
・同時編集や削除との競合が勝手に上書きされず、競合画面から明示的に解決できること。
・ウィジェットと共有入力から作成した通常メモが v2 に届くこと。
・旧メモへ戻ったとき以前の同期先が復元され、旧データが保たれていること。

【対象外・未確認】
このビルドは TestFlight のため CloudKit Production 環境を使います。端末間の実同期、実データ移行、認証、添付、再起動後の復元はこれから確認する項目です。有効期限付きの相互承認QRペアリング、外部IDだけでの管理者鍵の復旧、Google Drive/Web v2 は対象外です。

問題があれば、端末の iOS バージョン、再現手順、発生時刻、表示された診断コードを添えて TestFlight のフィードバックを送ってください。復旧コード、パスワード、メモ本文は報告に含めないでください。
