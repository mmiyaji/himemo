HiMemo Help and FAQ

Last updated: May 17, 2026

This page explains profiles, tags, archives, backups, cloud sync, and recovery steps that are too detailed to fit inside the Settings screen. The name HiMemo quietly nods to the Japanese phrase "秘メモ," a private memo.

How Profiles Work

What is a profile?

A profile is a workspace for viewing and storing notes. In normal use, you stay in the standard Notes profile and open a private profile only when you need that separate space.

What is the difference between the normal profile and a private profile?

The normal profile is the everyday note space shown when the app opens. A private profile is an additional space that opens only after you enter a matching password from the key icon.

Is a profile the same as an account or sync target?

No. A profile is a HiMemo display and storage space. It is separate from your iCloud or Google Drive account, cloud sync target, and device user account.

Recommended Workflow

HiMemo is designed for quick capture first, then later cleanup. Add a quick note when the thought appears, then refine the title, tags, attachments, and location when you have time. Search and tags usually work better than splitting notes into many small folders.

Use private profiles for spaces that should be clearly separated from everyday Notes, such as work, personal use, or a hidden area on a shared device. For ordinary topics, using tags inside the normal profile is usually easier than creating many private profiles.

External Quick Memo

When External quick memo is enabled in Settings, the home widget or Android share sheet can open a lightweight memo surface without opening the full app. Use it to quickly save thoughts, shared text, or information you want to organize later.

If private profiles are configured, External quick memo can also create a note in a private profile. It does not browse or edit existing notes. To read the saved note, unlock the private profile in the app as usual.

External quick memo is intended for quick creation only. Review the content, add tags or attachments, and check sync state later from the normal notes screen.

Use Tags Actively

Notes become harder to find if you wait until later to organize them. Add short tags when you create a note. Two to four tags per note for project, purpose, status, place, or person usually makes search and filtering easier.

Examples: work, idea, travel, receipt, review. Too many near-duplicate tags make notes harder to browse, so keep tag names short and consistent.

When Many Notes Feel Slow

As notes and attachments increase, list rendering, search, and sync may feel slower depending on the device or browser. First narrow the visible notes with tags and search, then consider moving old notes that you rarely use into archive views.

Before deleting long-term notes, export a file archive and confirm that it opens. Private profile archive keys and passwords cannot be recovered by HiMemo, so keep them in a safe place.

Backup and File Export

Cloud sync keeps multiple devices aligned. For backup, Settings also provides file backup and file export so you can save a ZIP archive in another trusted location.

Before migrating devices, switching sync targets, repairing attachments, or cleaning up old notes, create a file export in addition to relying on cloud sync. Unencrypted ZIP exports contain readable note text and attachments, so store them carefully.

Private Profiles

What is a private profile?

A private profile is a separate space that opens only when the entered password matches that profile. Use it when you want to keep different groups of notes separated. Settings does not list configured profile names or vault IDs.

What happens if I forget the password?

HiMemo cannot reset forgotten private profile passwords, unlock private profiles, or recover private profile data. Do not enter passwords, recovery keys, note contents, or other sensitive information in the contact form.

What can admin mode do?

Admin mode is used for private profile management actions such as adding profiles. Even in admin mode, HiMemo does not expose a list of configured profile names or vault IDs in Settings.

Cloud Sync

What is the cloud recovery key?

The cloud recovery key is used to decrypt sync bundles. To read sync data on another device, you may need to copy the cloud recovery key from the original device and import it on the new device.

What happens when switching between iCloud and Google Drive?

Changing the selected sync target does not automatically move existing bundles between cloud services. After switching targets, re-upload all notes from the original device to create a fresh bundle in the new target.

When should I use the sync detail buttons?

  • Refresh: Check the latest bundle information in the selected sync target.
  • Upload: Send this device's current changes to the sync target.
  • Re-upload all notes: Use after switching sync targets, repairing attachments, or rebuilding the remote bundle.
  • Download: Fetch the latest remote bundle to this device.
  • Review: Inspect a downloaded bundle before applying it.
  • Apply: Apply the downloaded bundle to this device's notes.

What if attachments do not open?

First check whether the attachment opens on the original device. If it does, re-upload all notes from that device. If another device cannot decrypt the bundle, the cloud recovery key may be different or iCloud Keychain may still be syncing.

Before Contacting Support

  • Check that the app and OS are up to date.
  • Confirm that the selected cloud account is correct.
  • Confirm that the cloud recovery key matches the original device.
  • Re-upload the latest state from the original device.
  • Create a file export backup when needed.

If the issue remains, use the HiMemo contact form without including sensitive information.
