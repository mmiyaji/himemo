HiMemo 使い方・よくある質問

最終更新日: 2026年5月17日

このページでは、設定画面だけでは説明しきれないプロファイル、タグ、アーカイブ、バックアップ、クラウド同期、復旧手順の考え方をまとめています。HiMemo という名前には、「秘メモ」のように個人的なメモを扱う道具でありたい、という小さな意味も込めています。

プロファイルの考え方

プロファイルとは何ですか？

プロファイルは、メモを表示・保存するための作業スペースです。通常は標準の Notes プロファイルだけを使い、必要なときだけ別のプライベートプロファイルを開きます。

通常プロファイルとプライベートプロファイルの違いは何ですか？

通常プロファイルはアプリを開いたときに表示される日常用のメモ領域です。プライベートプロファイルは、鍵アイコンからパスワードを入力したときだけ開く追加の領域です。

プロファイルはアカウントや同期先と同じですか？

いいえ。プロファイルは HiMemo 内の表示・保存領域の単位です。iCloud や Google Drive のアカウント、クラウド同期先、端末のユーザーアカウントとは別の概念です。

想定している使い方

まずはクイックメモで気軽に記録し、あとからタイトル、タグ、添付、場所などを整える使い方を想定しています。フォルダで細かく分けるより、検索とタグで見つけ直す運用が向いています。

プライベートプロファイルは、仕事、個人、共有端末上の非表示領域など、日常の Notes と明確に分けたい場合に使ってください。話題ごとに大量のプライベートプロファイルを作るより、通常プロファイル内でタグを使い分ける方が扱いやすくなります。

外部クイックメモ

設定で「外部クイックメモ」をオンにすると、ホームウィジェットや Android の共有メニューから、フルアプリを開かずに簡易メモ画面を使えます。思いついた内容、共有されたテキスト、あとで整理したい情報をすばやく保存するための入口です。

プライベートプロファイルを設定している場合でも、外部クイックメモからそのプロファイルへメモを作成できます。ただし、既存メモの閲覧や編集は行いません。保存したメモを読むには、通常どおりアプリ側でプライベートプロファイルのロックを解除してください。

外部クイックメモは「作成だけをすばやく行う」ための機能です。タグや添付の整理、内容の確認、同期状態の確認は、あとから通常のメモ画面で行う使い方をおすすめします。

タグを積極的に使う

件数が増えてから整理しようとすると見つけにくくなるため、メモを作るタイミングで短いタグを付けることをおすすめします。プロジェクト、用途、状態、場所、人名などを 1 件あたり 2〜4 個程度付けると、後から検索や絞り込みがしやすくなります。

例: 仕事、アイデア、旅行、領収書、要確認。似たタグを増やしすぎると逆に探しにくくなるため、短く一貫した名前にそろえてください。

件数が増えて重く感じる場合

メモや添付ファイルが増えると、端末やブラウザの状態によって一覧表示、検索、同期が重く感じられる場合があります。まずはタグや検索で表示対象を絞り込み、普段使わない古いメモはアーカイブ表示に移す運用を検討してください。

長期間参照しないメモは、削除する前にファイルエクスポートでアーカイブを作成し、開けることを確認してから整理すると安全です。プライベートプロファイルのアーカイブキーやパスワードは復旧できないため、必ず自分で保管してください。

バックアップとファイルエクスポート

クラウド同期は複数端末で同じ状態を保つための仕組みです。バックアップ目的では、設定の「ファイルバックアップ」からファイルエクスポートを行い、ZIP アーカイブとして別の安全な場所に保管する方法もあります。

端末移行、同期先の切り替え、添付ファイルの修復、古いメモの整理を行う前には、クラウド同期だけに頼らずファイルエクスポートも作成しておくことをおすすめします。暗号化しない ZIP にはメモ本文や添付が読める形で含まれるため、保存場所に注意してください。

プライベートプロファイル

プライベートプロファイルとは何ですか？

通常の Notes とは別に、入力したパスワードに一致するプロファイルだけを開くための領域です。用途ごとにメモを分けたい場合に使います。設定画面には登録済みプロファイル名や保存先 ID を一覧表示しません。

パスワードを忘れた場合はどうなりますか？

プライベートプロファイルのパスワード忘れ、ロック解除、データ復旧には対応できません。パスワード、復旧キー、メモ本文などの機密情報を問い合わせフォームへ入力しないでください。

管理者モードでは何ができますか？

管理者モードでは、プライベートプロファイルの追加や管理操作を行えます。ただし、管理者モードでもプロファイル名や保存先 ID を設定画面に一覧表示する設計ではありません。

クラウド同期

クラウド復元キーとは何ですか？

同期バンドルを復号するためのキーです。別端末で同期データを読むには、元端末のクラウド復元キーをコピーして新しい端末へ読み込む必要がある場合があります。

iCloud と Google Drive を切り替えた場合、過去のメモはどうなりますか？

同期先を切り替えるだけでは、別の同期先に保存済みのバンドルが自動的に移動するわけではありません。切り替え後は、元端末で全メモを再アップロードし、新しい同期先に最新バンドルを作成してください。

同期詳細のボタンはいつ使いますか？

  • 更新: 同期先にある最新バンドル情報を確認します。
  • アップロード: この端末の現在の変更を同期先へ送ります。
  • 全メモを再アップロード: 同期先切り替え後、添付修復後、同期先を作り直したい場合に使います。
  • ダウンロード: 同期先から最新バンドルをこの端末へ取得します。
  • 確認: ダウンロード済みバンドルの内容を適用前に確認します。
  • 適用: ダウンロード済みバンドルをこの端末のメモへ反映します。

添付ファイルが開けない場合は？

元端末で添付ファイルが開けるか確認し、開ける場合は元端末から全メモを再アップロードしてください。別端末で復号できない場合は、クラウド復元キーが違う、または iCloud Keychain の同期待ちである可能性があります。

問い合わせ前に確認すること

  • アプリと OS が最新であること
  • 同期先アカウントが正しいこと
  • クラウド復元キーが元端末と一致していること
  • 元端末で最新状態を再アップロード済みであること
  • 必要に応じてファイルエクスポートでバックアップを作成済みであること

それでも解決しない場合は、機密情報を含めずに お問い合わせフォーム から状況を送信してください。
