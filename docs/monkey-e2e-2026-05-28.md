# Monkey E2E testing - 2026-05-28

## Scope

- Added deterministic Playwright monkey coverage for home, editor, search, filters, tags, layout toggle, and bottom navigation.
- Each seed performs 70 randomized actions against seeded local notes.
- The test records page errors and console errors, and checks that raw Flutter/Dart exception text is not shown in the app.

## Runs

- `npm run e2e -- monkey.spec.js`: initially failed on seeds 1103, 1104, and 1105.
- `npm run e2e -- monkey.spec.js`: passed after narrowing navigation clicks to labeled tabs, 5 tests.
- `npm run e2e -- monkey.spec.js --repeat-each=3`: passed, 15 tests.
- `npm run e2e -- monkey.spec.js --repeat-each=5`: passed, 25 tests.
- `npm run e2e -- monkey.spec.js`: passed after ASCII-only selector cleanup, 5 tests.

## Finding

- The initial failures were caused by the monkey harness clicking the unlabeled center tab slot. Flutter Web exposed it as a tab, but the Add note floating action button intercepted pointer events. This was a test harness issue rather than a product failure.
- The harness now picks only labeled navigation tabs: Notes, Calendar, Insights, and Settings.

## Product result

- No reproducible product bug was found in this run across the repeated passing monkey cases.
- The exercised areas remained free of raw Flutter errors, page errors, and console errors during the passing runs.
