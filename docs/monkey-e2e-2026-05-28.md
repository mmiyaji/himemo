# Monkey E2E testing - 2026-05-28

## Scope

- Added deterministic Playwright monkey coverage for home, editor, search, filters, tags, layout toggle, and bottom navigation.
- Each seed performs 70 randomized actions against seeded local notes.
- The test records page errors and console errors, and checks that raw Flutter/Dart exception text is not shown in the app.

## Runs

- `npm run e2e -- monkey.spec.js`: initially failed on seeds 1103, 1104, and 1105.
- `npm run e2e -- monkey.spec.js`: passed after narrowing navigation clicks to labeled tabs, 5 tests.
- `npm run e2e -- monkey.spec.js --repeat-each=3`: passed, 15 tests.
- `npm run e2e -- monkey.spec.js --repeat-each=5`: passed, 25 tests.
- `npm run e2e -- monkey.spec.js`: passed after ASCII-only selector cleanup, 5 tests.
- `npm run e2e -- monkey.spec.js --repeat-each=10`: 49 passed, 1 startup wait timeout under 8 workers.
- `npm run e2e -- monkey.spec.js -g "seed 1105" --repeat-each=5 --workers=1`: passed, 5 tests. The 8-worker startup wait timeout did not reproduce in isolation.
- `npm run e2e -- detail-monkey.spec.js`: initially exposed detail monkey harness issues around disabled previous-note buttons, editor cancellation, and virtualized list items.
- `npm run e2e -- detail-monkey.spec.js`: passed after harness hardening, 3 tests.
- `npm run e2e -- detail-monkey.spec.js --repeat-each=5`: passed, 15 tests.
- `npm run e2e -- sync-google-drive.spec.js`: passed, 2 tests, used as the sync baseline before adding deeper sync monkey coverage.

## Finding

- The initial failures were caused by the monkey harness clicking the unlabeled center tab slot. Flutter Web exposed it as a tab, but the Add note floating action button intercepted pointer events. This was a test harness issue rather than a product failure.
- The harness now picks only labeled navigation tabs: Notes, Calendar, Insights, and Settings.
- A high-parallel `repeat-each=10` run produced one startup readiness timeout while 49 other cases passed. The same seed passed 5 times with one worker, so this is recorded as a high-load harness/server startup flake rather than a product bug.
- The first detail monkey draft hit disabled previous-note controls and editor-dialog cleanup races. The detail harness now skips disabled controls, clears list search before reopening details, and uses bounded editor-cancel fallbacks.

## Product result

- No reproducible product bug was found in this run across the repeated passing monkey cases.
- The exercised areas remained free of raw Flutter errors, page errors, and console errors during the passing runs.
- Multi-agent read-only exploration covered detail-view and fake Google Drive sync monkey candidates; detail-view coverage was implemented in `playwright/tests/detail-monkey.spec.js`.
