# HiMemo Store Listing Copy

Last updated: 2026-05-17

## Positioning

HiMemo is a private memo app for quick capture, personal records, and secure organization. The name quietly comes from "秘メモ": a private memo. Keep that origin as a subtle note, not the main tagline.

Primary value:
- Capture thoughts quickly.
- Keep different note spaces separated with private profiles.
- Protect local notes with app lock, encryption, backup, and optional sync.
- Review notes by date and writing activity.

### Description

HiMemo は、思いついたことをすばやく残し、あとから安全に見返すためのメモアプリです。名前には「秘メモ」のように、個人的なメモを扱う道具でありたいという意味を少し込めています。

1行目をタイトルにできるクイックメモ、日付で見返せるカレンダー、書いた量を確認できる記録画面で、日々のメモを軽く続けられます。

プライベートプロファイルを使うと、通常の Notes とは別の領域をパスワードで開けます。設定画面には登録済みプロファイル名や保存先IDを一覧表示しないため、共有端末や仕事/個人の分離にも使いやすい設計です。

メモや添付ファイルは端末内で暗号化して保存する設計です。必要に応じてファイルバックアップを作成したり、iCloud または Google Drive のアプリ専用領域を使って暗号化同期を利用したりできます。

主な機能:
- すばやいメモ作成とクイックメモ
- タグ、検索、ピン留め、日付変更
- 写真、動画、音声、ファイル、位置情報の添付
- カレンダーと記録画面での振り返り
- 複数のプライベートプロファイル
- PIN または端末認証によるアプリロック
- ファイルバックアップとエクスポート
- iCloud / Google Drive を使った任意のクラウド同期

パスワード、PIN、復元キーを紛失すると、プライベートプロファイルや同期データを復旧できない場合があります。重要なメモは、クラウド同期だけでなくファイルバックアップも併用してください。

## English

### App Name

HiMemo

### Subtitle / Short Description

Fast private notes with profile lock

### Promotional Text

Capture everyday notes quickly, separate private spaces with profile locks, and keep your records backed up with optional encrypted sync.

### Description

HiMemo is a private memo app for quick capture, personal records, and secure organization. The name quietly nods to "秘メモ," a private memo.

Use quick memo when a thought appears, then refine it later with titles, tags, attachments, dates, and search. Calendar and insights views help you review what you wrote by day and track your writing activity.

Private profiles let you open separate note spaces only when the entered password matches that profile. Settings avoids listing configured profile names or vault IDs, which helps keep separate work, personal, or shared-device spaces less exposed.

HiMemo is designed to encrypt notes and attachments on your device. You can create file backups, export archives, and optionally sync encrypted bundles through iCloud or Google Drive app-data storage.

Key features:
- Fast note creation and quick memo
- Tags, search, pins, and editable note dates
- Photo, video, audio, file, and location attachments
- Calendar and insights review
- Multiple private profiles
- App lock with PIN or device authentication
- File backup and export
- Optional iCloud / Google Drive sync

If you lose a password, PIN, or recovery key, private profile or sync data may not be recoverable. For important notes, use file backups in addition to cloud sync.

### What's New 1.0.0

This first public release includes quick notes, private profiles, app lock, attachments, file backup, and optional iCloud / Google Drive sync.
